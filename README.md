# fantasyrealm- (Base du projet)
Presentation du projet : 
 PixelVerse Studios souhaite améliorer l'expérience de personnalisation des avatars dans FantasyRealm Online.
 Faute de temps j'ai développé les pages accueil,menu,connexion,inscription, mot de passe oublié,contact,page personnages,mentions légales / CGV.
Fonctionnalité :
 - Accueil
 - Menu
 - Connexion
 - Inscription
 - Mot de passe oublié
 - Contact
 -Page personnages
 - Mentions légales
 - CGV
Fonctionalit non réaliser :
  - Espace utilisateur
  - Création de personnage
  - Perssonalisation(visage,couleur,accessoires...)
  - Validation employé
  - Gestion des avis
  - Espace administateur
  - Base de données sql
  - Base de données Nosql
  - Déploiement
  - Sécurite
  - Filtre sur la page personnages
Instalation local
 Il faut récupérer le dépôt Github ensuite ouvrir le fichier index.html dans un navigateur puis utiliser le menu pour accéder aux pages.
